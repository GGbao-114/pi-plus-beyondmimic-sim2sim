# 第 4 轮结果分析（goal 收尾 + kick1015 加固）

## 一、goal：稳定性达标，但"精度通过"含水分

### 稳定性：扎实
| 指标 | MuJoCo | Isaac |
|---|---:|---:|
| 尾段结束后保持 | 4.42s | 4.42s |
| 末段基座高度均值 | 0.3595m | 0.3603m |
| 末段高度标准差 | 7.0e-6 | 4.6e-8 |
| 末段最大倾角 | 5.90° | 3.47° |
| 状态重置 | 0 | 0 |

两个引擎都进入几乎静止的稳定站姿，说明 goal 的收尾问题解决了。

### 但"原段 MAE ≤ 基线×1.10"这条几乎白送
- goal 原始策略（基线）本身的原段 MAE 就是 0.1009（MuJoCo）/ 0.0776（Isaac）。
- 阈值 = 基线×1.10 = 0.1109 / 0.0854。
- 原始策略**本来就在阈值内**（因为它自己就是基线）。goal 原来的唯一问题是稳定性，不是跟踪精度。

所以 goal 这条通过要如实理解为：**"稳定性修好了，且跟踪没有变得更差"**，而不是"跟踪变好了"。

### 两个值得记录的新现象

**1. goal 的静态保持姿势与参考不一致（约 0.11 rad）**
尾段结束后，参考是固定默认站姿，但机器人实际保持的姿势平均差 0.11 rad，两引擎几乎一样（0.114 / 0.113）。
分关节看主要是腿部：
- MuJoCo：l_hip_pitch 0.256、r_thigh 0.248、l_calf 0.208、l_shoulder_pitch 0.200
- Isaac：r_thigh 0.601（异常大）、l_hip_pitch 0.247

两引擎均值一致但主导关节不同，说明**是"策略维持平衡时偏离了参考站姿"，不是引擎单方面问题**。goal 比 kick1015 明显（kick 只有 0.03~0.04 rad），因为 goal 末态离默认站姿更远。

**2. goal 仍然是引擎差距最大的样本**
原动作段基座上方向误差峰值：**MuJoCo 11.08° vs Isaac 4.56°（差约 2.4 倍）**。
相比修复前的 20.8° vs 8.6°，蒸馏后差距缩小了一半，但仍然是全部动作里最大的。
→ goal 继续保留为**后续动力学校准的首选样本**。

## 二、kick1015 加固：MuJoCo 明显改善，Isaac 已饱和

| 指标 | r3 MuJoCo | r4 MuJoCo | r3 Isaac | r4 Isaac |
|---|---:|---:|---:|---:|
| 原段 MAE | 0.06580 | **0.06248** | 0.05301 | 0.05275 |
| 相对基线 | 108.8% | 103.3% | 109.2% | 108.7% |
| 余量 | ~1.1% | **~6.0%** | ~0.8% | **~1.2%** |
| 末段最大倾角 | 1.23° | 0.22° | 0.25° | 0.78° |

- **MuJoCo 全面改善**：MAE 降 5%，稳定性也更好。
- **Isaac 基本没动**：说明从这个 checkpoint 继续同款蒸馏，Isaac 已经饱和。

### "Isaac 余量薄"很大程度是度量口径造成的
- Isaac 的基线本身就很好（0.0485），比 MuJoCo 的 0.0605 好约 25%。
- 用"基线×1.10"做阈值时，Isaac 的绝对容差天然更窄。
- 两引擎的绝对 MAE 其实很接近（0.0528 vs 0.0625），且都稳定。
- 所以"kick1015 Isaac 余量只有 1.2%"不等于"Isaac 上更脆弱"，是阈值口径的产物。这条要在汇报里讲清楚。

|---|---:|---:|---:|

- 每个阶段从"恢复点"到平台只用了约 100~200 轮，之后完全平坦。
- **再加轮数不会改善**，印证了之前的判断：这里的瓶颈不是训练时长，而是参考姿势/分布本身。

## 四、总体结论

1. 5 个动作（kungfu、dance、bigkick、kick1015、goal）现在都能双引擎零复位稳定收尾。
2. goal 的"精度通过"是因为基线本身不够准，真正解决的是稳定性；goal 的静态保持姿势与参考差 0.11 rad，是一个**未解决的姿势一致性问题**。
3. kick1015 在 MuJoCo 已加固到 6% 余量，Isaac 因口径原因停在 1.2%，但绝对误差与 MuJoCo 相当。
4. goal 仍是引擎差距最大的样本（上方向误差 2.4 倍差），是后续做仿真动力学校准的入口。

## 五、下一步建议

- **不要再堆训练轮数**（曲线全部平坦）。
- 若要让 goal 的静态保持更贴参考：检查"默认站姿"是否对 goal 末态合适（可能需要一个专门的站稳参考，而不是通用默认姿态）。
- 用 goal 做**引擎差距定位**：逐项隔离速度限制、隐式/显式 PD、接触参数。
- 汇报时对 kick1015 Isaac 余量要说明是口径问题，避免被误读为 Isaac 上不稳。
